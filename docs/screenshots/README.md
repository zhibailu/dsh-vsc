# Screenshots — 拍摄清单与放置规范

README 用这些截图展示功能。**高瘦图不要横着排**——竖长图并排会被压得很窄。规范做法：每张图独立成行、居中、按宽度缩放，这样竖长图也能看得清。

## 放置方式（README 里的统一写法）

- 每张图用 `width` 定宽，不设高度（高度自动按比例）。
- **竖长图**（侧边栏、对话）`width` 用 `280–320`，居中、上下堆叠。
- **横图**（右键菜单、设置）`width` 用 `340–420`。
- 图片文件名固定，放进本目录即可，README 自动生效。

## 拍摄小贴士

1. **侧边栏要饱满**：先把 VS Code 窗口拉高一点，让面板里同时有会话列表、一条带工具动作的消息、输入框，再截整块面板。宁可图长一点，也别缩。
2. **对比度**：截图用浅色或深色主题都行，但全仓库保持一致，别混。
3. **真实内容**：用真实代码和真实任务，别用假数据，展示的正是它真实干活的画面。
4. **不要带隐私**：确认截图里没有真实 API key、本地路径或个人文件内容。
5. **尺寸**：`width` 已由 README 控制，你只要保证 PNG 源图清晰（建议 ≥ 2× 显示宽度，即 ≥ 600px 宽）。

## 怎么把图接进 README

把文件放到本目录、文件名对上表后，README 里对应的 `<img src="docs/screenshots/xxx.png" ...>` 会自动显示，**不需要改 README**。新增的待拍图，等拍好后把 README 截图区的对应块补上即可。
