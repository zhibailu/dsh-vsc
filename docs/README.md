# docs — 公开用户文档区

| 项 | 说明 |
|---|---|
| **谁可见** | 公开（推送到 GitHub，用户可见） |
| **为谁负责** | 终端用户（README 引用、截图、用户指南） |
| **行为边界** | 只放**给用户看的**文档与素材 |

## 放这里 ✅

- `screenshots/` — README 引用的截图（sidebar.png / chat.png / ask-menu.png）
- 用户指南、FAQ、配置说明等面向使用者的文档

## 不放这里 ❌

- 复盘、规划、上游追踪等内部文档 → `internal/`
- 开发调试草稿 → `scratch/`
